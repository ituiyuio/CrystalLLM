# Exp 26: 局部 attention + 全局波场

**日期:** 2026-07-08
**分支:** cwf-manifesto
**状态:** GLOBAL_DEAD (全局信息对逐 token 预测无增量, 长上下文路线封死)

## 核心问题

exp25 证明: 冻结波场全局注入对全注意力 transformer 无增益 (信息冗余).
推测: 波场和 transformer 看同样的 256 token, 信息重叠 -> 冗余.

本实验: 强制 transformer 只看局部窗口 (前 64 token), 波场看完整 256 token.
制造信息不对称: 波场提供 transformer 看不到的信息.
朴素池化基线排除"任何全局信息都有用"的混淆.

## 设计

- 局部 causal mask: 位置 i 只看 [max(0, i-63), i] (窗口 64)
- 波场编码器: 冻结 Stage A, 看完整 256 token, gauge-fixed 全局 code
- 朴素池化: 冻结 embedding mean-pool -> Linear -> 全局 bias
- 4 条件 x 3 seeds x 5000 steps

## 分析

### 为什么信息不对称也不产生增益?

exp25 的假设是: 波场信息和 transformer 信息重叠 (都看 256 token) -> 冗余.
exp26 制造了信息不对称 (波场看 256, transformer 只看 64), 但仍然无增益.

原因: **256-token 窗口内的全局信息, 对逐 token 预测的边际贡献极低.**
即使 transformer 只看 64 个 token, 它能从局部上下文中提取足够强的统计规律,
全局信息 (来自 64-token 窗口之外) 对大部分 token 的预测没有增量.

具体来说:
1. **局部 64 token 足够预测大部分 byte**. 在 byte-level 任务中, 局部 n-gram
   统计已经覆盖了大部分可预测性. 全局上下文只对少数长程依赖 token 有用,
   但这些 token 在整体 PPL 中占比太小.
2. **全局 bias 注入太弱**. `wave_bias.unsqueeze(1)` 加到每个位置, 是一个
   常数偏移. LayerNorm 部分抵消它. 即使信息不对称, 注入方式限制了信息传递.
3. **probe 信息 ≠ 可用信息**. probe 23.3% 说明全局 code 含判别信息, 但这个
   信息是**全局的** (整个窗口的摘要), 对**逐位置**的 token 预测, 需要的是
   **位置相关**的信息, 全局摘要帮助有限.

### 对长上下文路线的最终判断

exp26 的"局部 attention + 全局波场"是长上下文路线的最便宜模拟.
即使在这种极端信息不对称下 (波场看 4 倍于 transformer 的窗口), 仍然无增益.

**这基本封死了"更长上下文窗口"的路线.** 如果 64 vs 256 的不对称都不产生增益,
64 vs 2048 的不对称大概率也不会 -- 因为问题不是窗口大小, 而是
**全局摘要信息对逐位置预测的固有冗余性**.

## 判决

**GLOBAL_DEAD.** 即使制造信息不对称 (transformer 看 64 token, 波场看 256),
全局信息 (波场或朴素池化) 对逐 token 预测也无增量. 长上下文路线封死.

### CWF 判别/预测路线的完整封口 (exp15-26)

| 路径 | 实验 | 结果 |
|---|---|---|
| 复数 attention 打分 | exp15 | FAIL (θ->0) |
| 全 holomorphic FFN | exp17 | FAIL (CR 约束) |
| 复数代数 | exp21 | FAIL (3.2x 差) |
| 频域推理 | exp22 | FAIL (5x 差) |
| 全复数 transformer (拆 junction) | exp23 | DEAD (中性) |
| JEPA 预测约束相位 | exp24 | DEAD (phase_std=均匀) |
| 冻结编码器全局注入 | exp25 | NEUTRAL (信息冗余) |
| 局部 attention + 全局波场 | exp26 | DEAD (信息不对称也无增益) |

**结论: 复数/波场在判别和预测任务中, 不论架构、损失、注入方式、信息覆盖范围,
都不提供增量价值. 唯一存活的复数优势是 Stage A 压缩 (2.7x), 但它对下游判别无增量.**

**下一步: 转向 B 方案 (波化生成器/diffusion).** 这是唯一未被封死的方向,
且波场的压缩优势 (2.7x) 在生成任务中不是冗余信息, 而是核心输入.
