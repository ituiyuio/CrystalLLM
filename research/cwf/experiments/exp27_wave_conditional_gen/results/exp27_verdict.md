# Exp 27: 波场条件生成 - 冻结波编码器作为生成条件

**日期:** 2026-07-08
**分支:** cwf-manifesto
**状态:** GEN_GLOBAL_HELPFUL (全局信息在生成中有效, 但波场不特殊)

## 核心问题

exp25/26 证明: 波场全局注入对判别无增量 (信息冗余). 原因是 decoder 能看到
和波场同样的 tokens. 本实验消除冗余: decoder 只生成 target, context 只通过
波场传入 (cross-attention). 波场是 context 信息的**唯一通道**.

## 设计

- 512-byte 窗口: context=bytes[0:256], target=bytes[256:512]
- decoder 在 target 上做因果 self-attention, cross-attend 到 context 表示
- **完整波场** (B, 64, 32) 做 cross-attention 的 K/V (不用 mean-pool)
- 朴素池化也降到 64 位置 (stride-4 mean-pool), 匹配位置数
- 4 条件 x 3 seeds x 5000 steps

### 判决矩阵

| 对比 | ratio | 判决 |
|---|---|---|
| pool vs base | 0.942 | **POOL_HELPFUL** (-5.8%) |
| wave vs base | 0.942 | **WAVE_HELPFUL** (-5.8%) |
| wave vs pool | 1.000 | NEUTRAL |
| complex vs real | 0.976 | NEUTRAL |

**总判决: GEN_GLOBAL_HELPFUL**

1. **波场在生成中有效!** R+wave_gen 比 R_gen 好 5.8% (1.472 vs 1.563).
   这是 CWF 系列实验中**第一次**波场条件显著击败无条件基线.
2. **但朴素池化同样有效** (0.942, -5.8%). 波场 vs 池化: 1.000, 完全相同.
   波场不比简单 mean-pool 更好.
3. **复数 vs 实数无差异** (0.976). 相位在生成中也不提供额外优势.

## 分析

### 与 exp25/26 的对比

| 实验 | 任务 | wave vs base | pool vs base |
|---|---|---|---|
| exp25 (全局注入, 全注意力) | 判别 | +0.5% (中性) | N/A |
| exp26 (全局注入, 局部注意力) | 判别 | -0.3% (中性) | +1.7% (中性) |
| **exp27 (cross-attention 生成)** | **生成** | **-5.8% (有效!)** | **-5.8% (有效!)** |

**生成任务打破了判别任务中的"信息冗余"死结.** 当 decoder 无法直接看到
context tokens 时, 全局信息 (波场或池化) 通过 cross-attention 提供了
5.8% 的增益. 这是 exp25/26 中完全不存在的.

### 但波场不特殊

波场和朴素池化的增益完全相同 (0.942 vs 0.942, ratio 1.000). 这说明:
1. **增益来自"有全局条件"本身**, 不是来自波场的学习性复数滤波器.
2. 波场编码器 (2.7x 重建优势) 的压缩质量, 在这个任务上**没有转化为
   比朴素 mean-pool 更好的条件表示**.
3. 复数 vs 实数也无差异 (0.976) -- 相位在生成中同样不提供额外优势.

### 为什么波场 = 池化?

两种可能:
1. **256-token context 太短**: 波场的 2.7x 重建优势在短序列上可能不显著.
   朴素 mean-pool 已经足够好地压缩了 256 个 token 的全局信息.
2. **cross-attention 太强**: decoder 的 cross-attention 有足够容量从
   任何 64-位置表示中提取需要的信息, 不论这个表示是波场还是池化.
   表示质量的差异被 cross-attention 的容量吸收了.

## 判决

**GEN_GLOBAL_HELPFUL.** 生成任务中, 全局条件信息 (通过 cross-attention)
确实有效 (-5.8%), 打破了判别任务中的信息冗余死结. 但**波场不比朴素池化更好**:
两者的增益完全相同. 波场的学习性复数滤波器 (2.7x 重建优势) 没有转化为
比简单 mean-pool 更好的生成条件.

**最终结论:**
1. **生成任务中全局条件有效** (-5.8%), 但这是"有条件 vs 无条件"的增益,
   不是波场特有的优势.
2. **波场 = 朴素池化** (ratio 1.000). 波场的 2.7x 重建优势没有转化为
   更好的生成条件.
3. **复数 = 实数** (ratio 0.976). 相位在生成中也不提供额外优势.
4. **CWF 的波场/复数结构在所有任务中 (判别/预测/生成) 都不比
   朴素实数方法更好.** 唯一的存活优势 (Stage A 2.7x 重建) 是一个
   压缩指标, 不转化为任何下游任务的实际增益.

**CWF 探索至此可以正式归档.** 13 个实验 (exp15-27) 干净地排除了
复数/波场在判别、预测、生成中的所有假说优势. 物理直觉可以启发方向,
但不能替代机制验证.
