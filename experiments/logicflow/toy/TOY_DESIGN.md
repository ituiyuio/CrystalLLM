# LogicFlow 玩具代码设计（Toy Design v0.1）

**日期**: 2026-09-07
**目标**: 用 1-2 周、单卡 5090，证伪/证实三个前提假设。
**纪律**: 每个阶段有终止门；玩具任务用合成数据（可编程 CoT、答案可验证、
变量全可控）；不写任何为"未来大系统"准备的抽象——每个文件用完可弃。

---

## 0. 玩具任务设计（关键决定）

**任务**: 模板化多步算术应用题。理由：
1. CoT 完全可编程生成（教师轨迹的"真值"已知，可验证教师是否忠实）
2. 推理深度可控（1-8 步），天然测「思考预算 vs 推理深度」
3. 答案自动判分，无需 LLM judge

```
模板: 小明有 {a} 个苹果，买了 {n} 袋每袋 {b} 个，送走 {c} 个，还剩几个？
CoT:  先算总数：{a} + {n}×{b} = {t}。再算剩余：{t} - {c} = {ans}。
深度旋钮: 步数 2~6，数字规模 1~99，干扰句 k 句
```

**教师**: Qwen2.5-1.5B-Instruct（5090 fp16 稳跑，d=1536）。
Teacher prompt 要求输出固定格式 CoT，温度 0。

**为什么不是 7B**: 玩具阶段所有结论是"可扩散性/因果性"这种定性判定，
1.5B 足够；且迭代速度快 5 倍。

## 1. 阶段一（E-T0）：思维空间可扩散性 —— 半天~1 天

**问题**: 教师隐态轨迹加噪后，去噪器能恢复吗？（不成立则换加噪族/换空间）

### 流水线

```
teacher_collect.py
  生成 5k 条模板题 → 教师逐条 CoT → 记录 CoT 段每个 token 的
  最后一层隐态 h_t ∈ R^1536 → 按句子/等号分段池化成 r 个寄存器
  (r=固定 8, 不足补零+mask) → RMSNorm → 存 .npz
  ⚠ 顺带记录: 每条的 (题目, CoT 文本, 答案, 段边界) 供后面用

dataset.py
  TrajectoryDataset: {ctx_embedding(题目末隐态), τ_clean r×d, mask}
  加噪（1.11 勘验后改用 ELF 式 rectified-flow 插值, 替代 DDPM 式 σ）:
    z_t = t·τ_clean + (1−t)·ε·noise_scale,  t ~ logit_normal(-0.8, 0.8)
  去噪器预测 x0 或 v=(x−z)/max(1−t,ε)（ELF 同款）

denoiser.py
  小 transformer: 4 层, d=512, 8 头, 因果掩码(寄存器 t 只看 ≤t),
  输入 = [z_t + t_embedding + ctx_embedding], 输出 = τ_clean/v 预测
  参数量 ~5-10M（4090/5090 上分钟级一轮）

train_et0.py
  训练 → 报告: 各 t 水平的 relative reconstruction error
  (||τ̂−τ||/||τ||) + 与两个朴素基线对比:
    B1: 全局均值预测 (下界)
    B2: 条件 copy: 直接返回 ctx 无关的 batch 均值轨迹 (下界)
```

### 门 G1（终止判据）
- 中低噪声 (t ≥ 0.5) 的重建误差显著低于 B1/B2（≥30% 相对改善）
- 且重建的寄存器用线性探针可解码出中间数值（如"11"）——**思维不只是
  可压缩，是可定向恢复的**
- 不过 → 换加噪族（token 级遮蔽腐蚀）重试一次 → 再不过换空间 → 终止

## 2. 阶段二（E-T2）：单步漂移 vs 多步扩散 —— 1~2 天

**问题**: Drifting 单步生成的思维轨迹，质量损失相对多步 FM 有多大？

```
train_et2.py  三个目标同架构训练 (1.11 勘验后升级三路对比):
  FM 分支:    flow matching 多步 (欧拉 8 步, ELF 同款插值/v-pred)
  Drift 分支: L = ||f_θ(ε,ctx) − stopgrad(f_θ(ε,ctx) + ηV)||²,
              V = attention(τ_gen, 教师池) − τ_gen (median-heuristic 带宽)
  FlowMap 分支: FMLM* 式 flow-map 蒸馏 (借 third_party/elf_star 实现)
  推演演化: 每 epoch 用当前 f_θ 重生成 25% 训练样本再漂移
评估: 轨迹质量 = 去码探针(寄存器→数值)正确率 + 轨迹间多样性
```

### 门 G2
- 1-step Drifting 的探针正确率 ≥ 8-step FM 的 50% → 主张"few-step"
- ≥ 80% → 主张 "one-step"（论文标题成立）
- < 50% → 假设降级为"多步思维扩散 + 自适应停机"（DoT+停机，故事变小）

## 3. 阶段三（E-mini）：解码接口 + 因果效用 —— 2~3 天

**问题**: 收敛寄存器能解码成正确答案吗？思维是因果有用的吗？（C1/C4）

```
decode_interface (三条路径, E-mini 只做前两条, 择优):
  P1 Coconut 式: τ[r-1] 作为冻结教师 input embedding 回喂,
     LoRA(输入层+前2层) 微调让它接 "答案：" 继续
  P2 小解码头: 2 层 transformer, 输入寄存器, 输出答案 token 序列
  (P3 ELF 式全 embedding 序列生成 → 留给大阶段, 玩具不做)

因果效用消融 (C1/C4 协议的玩具版):
  A1 完整模型
  A2 寄存器置零 → 解码
  A3 寄存器加噪(σ=σ_data) → 解码
  A4 寄存器替换为错题的寄存器 → 解码
  判据: A2/A3 相对 A1 的答案准确率下降 Δ
```

### 门 G3
- P1/P2 任一路径：A1 准确率 ≥ 60%（玩具任务上"模型学会了思考"）
- **Δ ≥ 15 个点** → 思维因果有用，C-4 协议成立，全叙事成立
- Δ < 5 个点 → **思维是装饰** → 项目级止损信号（叙事不可救）
- 5 ≤ Δ < 15 → 灰色区：增加 L_decode-through 权重重训一轮再判

## 4. 顺带测量（便宜，不设门）

- 结晶曲线: 线性探针"答案可解码度 vs 思考位置"（寄存器摆放依据）
- ‖V‖ 随迭代衰减形态（停机信号有效性）
- 承重过滤 A/B: 教师轨迹"滤承重位 vs 不滤"训练出的去噪器质量对比

## 5. 文件布局

```
experiments/logicflow/toy/
├── TOY_DESIGN.md          ← 本文档
├── teacher_collect.py     # 教师隐态采集 (~150 行)
├── dataset.py             # 轨迹数据集 + σ 标定 (~100 行)
├── denoiser.py            # 因果寄存器去噪器 (~120 行)
├── train_et0.py           # 阶段一: 可扩散性 (~150 行)
├── train_et2.py           # 阶段二: 单步漂移 vs 多步 FM (~200 行)
├── train_emini.py         # 阶段三: 解码接口 + 消融 (~250 行)
└── eval_protocol.py       # 探针/消融/结晶曲线 (~150 行)
```

依赖: 现有 venv (torch 2.9.1+cu128) + transformers (教师加载)。
预计总代码量 ~1100 行，全部为一次性玩具质量——禁止抽象成"框架"。

## 7. 三道门的决策树

```
G1 过? ──否──→ 换加噪族/换空间 → 仍不过 → 终止
  │是
G2 过? ──否──→ 降级 few-step 叙事 (继续)
  │是
G3 过? ──否──→ 止损信号 (negative-result 工作坊)
  │是
  └──→ 全叙事成立 → 进入 E2 最小实例 (真语料)
```
